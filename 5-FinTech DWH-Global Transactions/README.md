# 📊 FinTech DWH: Global Transaction Analytics Platform

> Построение инкрементального ETL-пайплайна из PostgreSQL в Vertica с автоматическим формированием витрины данных `global_metrics` для ежедневного мониторинга транзакций, мультивалютной аналитики и расчёта оборота компании в долларовом эквиваленте.

---

## 🎯 Описание проекта
Финтех-стартап, предоставляющий международные банковские услуги через мобильное приложение, нуждался в консолидированной аналитике транзакционной активности пользователей из разных стран. Существовала децентрализованная система учёта по странам, что затрудняло получение единой картины оборота компании.

**Цель проекта** — построить автоматизированный пайплайн для ежедневной загрузки транзакций и курсов валют из операционной PostgreSQL в колоночное хранилище Vertica, а также создать аналитическую витрину для ответа на ключевые бизнес-вопросы:
- Ежедневная динамика сумм переводов в разных валютах
- Среднее количество транзакций на пользователя
- Количество уникальных пользователей, совершающих транзакции
- Общий оборот компании в долларовом эквиваленте

## 🏗️ Архитектура решения
**Многослойная модель данных:**
- **STG-слой** (`VT251109CA442B__STAGING`) — сырые данные из PostgreSQL:
  - `transactions` — транзакции пользователей
  - `currencies` — ежедневные курсы валют
  - `srv_wf_settings` — метаданные инкрементальной загрузки
- **DWH-слой** (`VT251109CA442B__DWH`) — аналитическая витрина:
  - `global_metrics` — итоговая агрегированная витрина с ежедневными метриками

**Двухэтапный ETL-процесс:**
1. **Инкрементальная загрузка** (DAG `data_import_dag`) — ежедневное обновление STG из PostgreSQL с отслеживанием контрольных точек
2. **Обновление витрины** (DAG `datamart_update_dag`) — ежедневный расчёт агрегатов за предыдущий день с конвертацией в USD

## 🛠️ Технологический стек
- **Хранилище:** Vertica (колоночная СУБД)
- **Источник данных:** PostgreSQL (операционная БД)
- **Оркестрация:** Apache Airflow
- **Языки:** Python, SQL
- **Библиотеки:** psycopg2, vertica-python
- **Архитектура:** Инкрементальная загрузка, снежинка (STG → DWH)

## 🔄 Ключевые особенности реализации
- **Инкрементальная загрузка** с механизмом контрольных точек через таблицу `srv_wf_settings`
- **Партиционирование** данных в Vertica по дате для оптимизации запросов
- **Конверсия валют** в реальном времени через JOIN с актуальными курсами
- **Идемпотентность** DAG'ов — безопасность повторных запусков
- **Автоматическое управление соединениями** через контекстные менеджеры
- **Логирование прогресса** загрузки с пороговыми значениями

## 📈 Бизнес-метрики в витрине
| Поле | Описание |
|------|----------|
| `date_update` | Дата расчёта (за предыдущий день) |
| `currency_from` | Код валюты транзакции |
| `amount_total` | Общая сумма транзакций по валюте в USD |
| `cnt_transactions` | Общее количество транзакций по валюте |
| `avg_transactions_per_account` | Среднее количество транзакций на аккаунт |
| `cnt_accounts_make_transactions` | Количество уникальных аккаунтов |

## 🧪 Результаты проекта
✅ **Автоматизированный ETL-пайплайн** — ежедневная загрузка данных без ручного вмешательства  
✅ **Единая валюта отчётов** — конвертация всех транзакций в USD по актуальным курсам  
✅ **Масштабируемая архитектура** — поддержка растущего объёма транзакций через партиционирование  
✅ **Прозрачность загрузки** — полное логирование и отслеживание контрольных точек  
✅ **Готовое аналитическое решение** — витрина `global_metrics` для дашбордов и отчётности
