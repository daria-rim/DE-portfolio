# 📊 Analytical Database: Social Media Group Engagement Analysis

> Расширение аналитического хранилища данных (DWH) новым источником — логами действий пользователей в группах — и создание механизма для идентификации сообществ с высокой конверсией вовлечения участников.

---

## 🎯 Описание проекта

Существующее аналитическое хранилище было построено для анализа пользовательской активности социальной сети. В рамках данного проекта хранилище расширяется **новым источником данных**:

1. **Логи действий пользователей в группах** (`group_log.csv`) из S3, содержащие:
   - События вступления/выхода из групп
   - Создание групп
   - Информацию о приглашениях между пользователями

**Цель** — определить группы с **высокой конверсией в первое сообщение**, чтобы маркетологи могли эффективно размещать рекламу соцсети на сторонних площадках, продвигая наиболее вовлекающие сообщества.

### 📈 Ключевая метрика: Конверсия в первое сообщение

```
group_conversion = cnt_users_in_group_with_messages / cnt_added_users
```

Где:
- `cnt_added_users` — количество пользователей, вступивших в группу
- `cnt_users_in_group_with_messages` — количество участников, написавших хотя бы одно сообщение

### 🏗️ Архитектура решения

**Многослойная модель Data Vault 2.0**:
1. **Staging слой** (`*_STAGING.group_log`) — сырые данные из S3
2. **DDS слой** — нормализованная структура:
   - Хабы: `h_users`, `h_groups`
   - Линки: `l_user_group_activity` 
   - Сателлиты: `s_auth_history`
3. **Расчётные CTE** — временные таблицы для аналитики

### 🔄 ETL-процесс
- **Airflow DAG** для загрузки данных из S3 в Vertica
- **SQL-миграции** между слоями хранилища
- **CTE-запросы** для расчёта финальных метрик

### 🛠 Технологический стек
- **Хранилище**: Vertica (колоночная СУБД)
- **Оркестрация**: Apache Airflow
- **Источник данных**: Amazon S3
- **Архитектура**: Data Vault 2.0
- **Языки**: SQL, Python (pandas)
- **Обработка данных**: CTE, оконные функции, JOIN-операции
